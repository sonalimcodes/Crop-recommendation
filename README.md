# 🌱 Crop Recommendation System

A Machine Learning-based Crop Recommendation System that predicts the most suitable crop to cultivate based on soil nutrients and environmental conditions. The system helps farmers and agricultural professionals make informed decisions to improve crop yield and productivity.

---

## 📖 About

The Crop Recommendation System uses Machine Learning algorithms to analyze soil and weather parameters and recommend the most suitable crop for cultivation.

The prediction is based on the following input parameters:

- Nitrogen (N)
- Phosphorous (P)
- Potassium (K)
- Temperature (°C)
- Humidity (%)
- Soil pH
- Rainfall (mm)

The project aims to support smart farming by providing accurate crop recommendations using historical agricultural data.

## ⚙ Installation

### 1. Clone the repository

```bash
git clone https://github.com/sonalimcodes/Crop-recommendation.git
```

### 2. Navigate to the project folder

```bash
cd Crop-recommendation-main
```

### 3. Install the required packages

```bash
pip install -r Requirements.txt
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 5. Open the notebook

Open:

```
Notebook/Crop recommendation final.ipynb
```

Run all the cells to train the model and make crop predictions.
